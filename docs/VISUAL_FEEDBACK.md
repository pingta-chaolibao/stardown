# 统一视觉反馈

本套效果经用户完整预览并统一确认后集成。表现层读取动作前后快照，规则层仍以一次有效方向输入原子结算；没有改变地图、英雄能力、伤害、视线或撤销规则。

| 反馈 | 表现 |
| --- | --- |
| 移动、推拉 | 0.16 秒短动画；整列对象共用进度，无部分移动 |
| 蓝英雄交换 | 0.20 秒两端闪现与局部粒子；不经过中间格 |
| 水晶 | 锚定格子的低幅呼吸，不漂移、不改变碰撞 |
| 能量开关 | 消散 / 凝聚；消失时仍保留原配色虚线格边与地纹 |
| 火龙 | 朝向箭头与 0.18 秒短火焰，只画到本步锁定的首目标或阻挡 |
| 哥布林 | 四向攻击短划痕，不示意斜角伤害 |
| 死亡、毁晶 | 0.22 秒淡出或碎裂残影，不继续占据逻辑格 |
| 其他已确认反馈 | 受阻、推拉接触、压板、选择、撤销与胜利的短时局部提示 |

没有全屏频闪、外部美术依赖或新增音频。当前英雄保留高亮与脚下选择圈；其他英雄压暗但保留红、绿、蓝色相。

## 输入与中断

方向输入在短时动作动画结束后才接受，不排队、不靠长按连走；键盘释放始终正常处理。C 和屏幕切换仍免费、不写撤销、不触发攻击；动画中切换不会取消正在展示的整步动作。撤销仍撤最近一次真实行动并保留当前选择。

Undo、正常重开、切关、返回主界面会清除旧反馈；所有位置仅由当前模型绘制，没有延迟 Tween 回调回写世界。死亡锁不变：任意英雄死亡后，只能撤销复活，不能用 C、重开或返回选关绕过。无效移动只给轻微受阻提示，不推进火龙攻击回合。

## 实现与检查

- `scripts/view/feedback_events.gd`：只读身份快照与动作事件；攻击取移动及机关更新后的共同状态，保留同一步互杀，不重复执行伤害。
- `scripts/view/feedback_timeline.gd`：有界表现时钟，负责位置插值、残影和取消；不接触规则层。
- `scripts/view/board_view.gd`：程序绘制；不创建常驻粒子节点或逐步积累事件。
- `tests/feedback_regression.gd`：模型不变、整链、交换、攻击截断、死亡与取消；读取全部 29 关合法路线。
- `tests/feedback_scene.gd`：真实键鼠、动画内重复输入 / 撤销 / 重开 / 切关 / 选择、死亡锁、大小窗口。

执行 `python3 tools/verify.py --visual --display :97` 可完整复测。最终执行范围与结果见 [VERIFICATION.md](VERIFICATION.md)。第 29 关新版正式录像额外保留逐步动画采样，校验每次动作间动画已结束且期间世界未变；原前 28 关历史录像不重录。
