# 火龙（fire_dragon）

火龙是独立的怪物类型，不能继承哥布林的四向相邻攻击。数据中必须明确 `facing` 为 `up`、`down`、`left` 或 `right`。它不主动移动、不转向；红英雄可以推入混合链，蓝英雄可以交换，位移保持朝向。绿英雄仍只能拉一个水晶。

每次成功的实际行动完成位移、压力与能量结算后，每只存活火龙只沿固定朝向查询一次最近的存活英雄或怪物，击杀这一个目标；同一步不会继续扫描被击杀对象后面的目标。下一次有效行动才能击杀后面的对象。水晶挡火且不被火焰摧毁；墙、草丛和实体能量块也挡火，消失能量格不挡。

加载没有额外火焰攻击轮次。C/屏幕切换、未成功的行走/推动、无效方向、单纯绘制或查询都不推进攻击。没有等待、攻击技能键、计时攻击或帧循环攻击。

能量再现仍先杀死格内怪物，已死亡火龙不发射火焰。死怪物保留身份用于撤销，但不占格、不挡目标、不攻击。任何英雄被击杀后锁住全队，只有撤销能够复活；C、重开、返回选关和重进不能绕过。一次撤销恢复移动、怪物生命、固定朝向、水晶、机关、所有英雄生命及实际行动计数。

## 显示与查询

每只火龙有清晰的固定方向箭头；橙色地面箭纹表示当前朝向、当前遮挡下下一次行动会触及的火线，并在首目标或阻挡前停止。它是只读预览，不表示正在计时攻击。哥布林继续使用四向危险框。关卡卡片区分火龙与哥布林，怪物不能被选为英雄或满足终点。

## 同时攻击与未定义组合

用户已确认：两只火龙互射同时死亡；哥布林可以击杀相邻火龙，双方互相满足攻击条件时同时死亡；开门时火焰击杀哥布林、哥布林同时相邻英雄，哥布林与英雄也同时死亡。

移动与机关更新后，先由共同的存活状态采样所有怪物目标，再统一应用攻击死亡。攻击者本步被击杀不会取消已成立攻击，但死怪物下一步不攻击。每只火龙只有一个锁定目标，本步不因目标死亡重新扫描。哥布林没有增加互杀行为，未知未来类型也不继承攻击行为。

火焰能否跨栅栏、怪物是否能压板也尚未确认；本关不存在这些组合，遇到它们同样显式报告，不能把假定规则用于通关。
