# 哥布林与公共怪物类型、攻击结算

怪物不是英雄，也不是水晶。schema 1 新增可选的 `monsters` 类型/坐标数组，省略等同没有怪物；原21关数据不迁移。数组索引是稳定身份，运行态单独保存每只怪物的位置和生死。

```json
"monsters": [
  {"kind": "goblin", "position": [10, 0]},
  {"kind": "goblin", "position": [5, 2]},
  {"kind": "goblin", "position": [10, 4]}
]
```

解析校验独立的地图内整数地板坐标，拒绝重复、墙内、越界及与英雄/水晶/草丛重叠。怪物可在目标上，但不满足英雄目标，也不进入 C 选择列表。

当前支持 **`goblin / 哥布林`** 与 **`fire_dragon / 火龙`**。数据必须明确kind；省略kind或未知未来类型会被拒绝。`MonsterRules.threatens(kind,...)`和表现层按类型分派，静止/四向攻击只属于哥布林，不会作为未来类型的默认行为。公共位置/生死、能量杀怪与原子撤销保持通用；火龙通过独立射线规则分派；没有添加用户尚未定义的其他怪物或大型类型框架。

## 用户已经确认的哥布林规则

- 哥布林不会主动移动。活哥布林杀死曼哈顿距离恰好为1的任何英雄，包括非当前英雄；斜角不攻击。
- 英雄进入范围后立即死亡，下一次方向输入不能靠把面前怪物推走来逃避已经发生的死亡。
- 红人可以隔着水晶推动怪物，沿用整列英雄/水晶/怪物原子推动。无隔晶的活英雄已经处于相邻死亡状态，不能发起直接推怪。
- 蓝人沿本次输入方向与第一个可见活怪物交换；视线遮挡、首目标优先及普通走动回退保持既有规则。交换完成后结算新位置的攻击，可能因此死亡；非当前对象不会触发自身能力。
- 绿人仍只自动拉背后最近的一枚水晶，不拉怪物或英雄。
- 能量块再现会杀死所在怪物；被杀死的怪物不再攻击。撤销一次完整恢复该步所有英雄、水晶、怪物、压力板/能量及生死。
- 任一英雄死亡仍只能撤销恢复，C、重开、切关、Back/Esc都不能绕过。

## 结算与实现选择

为避免没有撤销历史的出生死局，本实现沿用固态能量起点校验方式，拒绝初始就在活怪物四向攻击范围内的数据。这是工程输入校验，当前确认地图的起点安全，不依赖该选择。

`grid_state.gd`保留同一移动/混合链和交换流程；`monster_rules.gd`只提供纯数据威胁与生死结算，不包含计时器、AI或渲染。每次合法输入先计划所有位置，再由已有EnergyRules计算占用/压力/能量及水晶毁坏/英雄死亡，接着处理能量再现杀怪，最后仅由剩余活怪物检查所有英雄的四向相邻。全部候选校验成功后才建立一次快照并提交，因此没有部分位移或漏掉的怪物生死。

死亡怪物的**表示选择**是退出碰撞、交换目标和攻击集合，保留身份/最后位置以支持撤销。画面仅留不占格、不可交互的淡色地面遗痕；能量再次消失不会自动复活怪物。没有增加尸体推动、障碍、奖励或其他新玩法。英雄可在能量消失后进入该格，这一选择有独立回归覆盖。重开在英雄存活时仍恢复全关初态，英雄死亡时继续锁定。

只有含怪物的快照/回放附加怪物位置、生死和死亡原因；旧单英雄与多英雄快照形状、原21段逐输入证据保持兼容。记录器和独立Python校验器都明确区分hero/crystal/monster三类，不能以相同数字ID混用对象类型。

## 尚未定义的组合边界

第36关用户已明确确认：**活哥布林能压住压力板，死亡后不再持压**，与英雄和水晶共同参与所有压板的全局AND。旧JSON无需修改，原 `pressure_sources` 仍过滤英雄/水晶，公共结算额外采集活哥布林。攻击死亡后同一步释放压板并结算能量恢复，完整Undo恢复生死、占用与两类能量。不能将这条确认推广到火龙或未来怪物。

其他怪物压板、哥布林隔栅栏攻击仍未定义；遇到这些组合模型返回明确的 `rule_unresolved` 及原因，保留原状态、不计步、不写撤销历史。这是未支持组合的技术限制，不是已确认的原作规则。

第22关没有压力板、能量块、栅栏或水晶，不依赖上述边界，不因它们阻塞交付。能量杀怪的已确认组合用独立夹具验证，不冒充本关可达演示。

## 验证与视觉

- `monster_regression.gd`覆盖四向死亡/四斜角安全、已死亡英雄不能再直接推怪、隔晶多怪推动及整链受阻、混合英雄链、同次多个非当前英雄死亡、蓝换怪及换位后第二怪击杀、绿单拉不带动后方怪物、能量先杀怪、死亡怪物不攻击/不交换/不占格，以及英雄/怪物/水晶同次能量结算和完整撤销。
- `check_monster_replays.py`独立核对真实GridState输出的三种逻辑夹具：蓝换怪、红隔晶推、能量先杀怪，并验证三种状态篡改和三种未知类型配置被拒。明确为无头逻辑验证，不使用虚假的X11或视频标签；正式媒体仍强制实际X11记录。
- `north_22_regression.gd`核对全部55格、更正的2/12/34、三怪稳定身份、8个四向危险格、14步合法路线、死亡锁、完整撤销/重开及前21关历史隔离。
- `north_22_scene.gd`用实际方向键/WASD/屏幕按钮检查重复输入、死亡反馈/菜单锁/撤销、斜角通行和明确胜利。1280×820和960×615均验证危险格边界像素，斜角不能着色为攻击范围。

怪物采用独立尖角轮廓、暗色身体、发光眼睛和牙齿，不使用英雄小人或选择圈。锈红色格边/浅底只标四向危险格；英雄死亡显示白色叉号与怪物原因，能量杀怪另有状态提示。原关21段通关视频、导航与能量短片不重录。


火龙已新增为独立 `fire_dragon` 类型，固定朝向/逐行动首目标射线攻击；不套用哥布林四向范围。详见 [FIRE_DRAGONS.md](FIRE_DRAGONS.md)，未定义组合明确报告而不假定。
