新关卡回归逐格检查全部 33 个内部坐标及外部边界，核对玩家、四格墙、蓝紫水晶身份及终点坐标。还覆盖玩家碰墙、蓝水晶受右下墙阻挡、紫水晶受外部边界阻挡、走开不拉水晶、两个水晶实际参与通关、胜利只在玩家进入终点后发生、胜利后的撤销、完整撤销链、胜利后重开，以及快速连续按下 / 释放、系统回声和重复事件。

推动规则按用户确认修正为：紧密排成直线的整列水晶与英雄每次各前进一格，不设 3 或 4 枚的数量硬上限。先扫描到列末空地，再从远端向近端移动；列末为墙或边界时整次不动、不计步、不记录历史。一次成功推动无论水晶数量都只算一步、一次推动、一次撤销。

连推回归覆盖 2、3、4、8、60 枚水晶的上 / 下 / 左 / 右推动，逐枚验证坐标和身份；覆盖墙与四边边界的原子阻挡、空格截断、旁侧水晶不随动、连续推动后单步撤销整列、重开恢复全列以及输入去重。60 枚用例验证规则未设置较小的数量上限。

通用回归保留单枚推动、地图非法数据、终点上有水晶不判胜、无推动也可到终点、焦点丢失、全部按键映射，以及固定随机种子的 1,000 次动作与逆序撤销。旧的“第二枚水晶一律阻挡”断言已按确认规则改为连续两枚可整体推动。

实际场景通过 `Input.parse_input_event` 注入键盘和鼠标事件，使用真实输入入口和 GUI 命中，没有以触发按钮信号替代鼠标点击。测试核对界面不再显示临时地图说明、计数、通关提示、撤销按钮状态及 1280 × 820 / 960 × 615 下可见控件边界；额外使用 2 / 3 / 4 枚测试水晶列，经真实键盘入口验证每次输入整列只前进一步，并用 GUI 撤销 / 重开恢复整列。测试夹具不作为可玩第二关。
