## 第十三关与多英雄

7×7 用户确认地形，红人(2,2)、蓝人(2,4)，初始选中蓝；两水晶(0,1)/(0,4)，双红圆终点(0,2)/(0,5)，黄板(5,1)/(5,5)，能量格(5,3)。保留2号(1,0)、11号(3,1)空地与46号(3,6)墙。49格地形逐项核验，没有修改确认地图。

同一 GridState 扩展稳定英雄身份与全体位置 / 生死，旧版 player 数据规范化为单英雄，前十二关不迁移。C 和屏幕按钮循环切换，仅选中英雄接收方向；非当前英雄保留本色并压暗，当前有描边与脚下圈。红英雄原子推动不限长的英雄 / 水晶混合列；蓝方向首可见对象被动交换，否则走一格。被推 / 交换的英雄不发动能力，选中身份不随位置互换。无新绿色或灰色英雄。

C 计一次有效操作 / 一次切换 / 一次撤销历史，不移动、不结算压力或能力；单英雄C不动作、不计数。撤销恢复全部英雄、水晶、身份、计数、选中、各自生死、压力和屏障。任意英雄死亡锁住全部行动、C、重开与切关，必须撤销复活。两名存活英雄需分占两个不同终点，不限定对应，水晶无效。

前十二关地图、解法、MP4与回放48份文件逐字节等同基线 `133f20836428f503a8ac6a7be1e579688c1f663f`；历史媒体条目保留。既有红推 / 绿单拉 / 蓝被动交换及机关模型和真实输入全部回归。

## 独立合法解

`DRRRCURRRCULLLULLDDCLLLDLLU`：27次操作 =24次方向+3次C，含2次交换、22次行走、0推拉。第9次两英雄压满板；第11次蓝人隔开门与红人交换，选中蓝不变；第12次离板后关门且二人安全；第19次蓝人到上目标，第27次红人到下目标。

`tools/check_north_13.py` 独立构造并重算每一步，再由 Godot 模型与实际键盘完整执行。不是穷举或最优性声明。路线仅移动上方水晶，下方水晶保持原位不影响胜利。混合长列推另用独立夹具验证，不伪称本关路线有推动。
