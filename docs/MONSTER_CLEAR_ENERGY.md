# 清怪能量与哥布林互杀

这是用户确认的公共机制，使用 `energy_blocks` 的明确类型判断，与颜色无关。旧 `energy_links` 仍由全体压板 AND 控制，两种类型可以共存，但不能在同一格指定相互冲突的条件。

```json
"energy_blocks": [
  {"kind": "all_monsters_defeated", "position": [9, 4]}
]
```

所有已实现类型的存活怪物（哥布林、火龙）都计数。只要至少一只存活，该类型能量块挡移动、挡视线；最后的死亡在本步统一结算后，全部清怪能量立即消失。初始零怪物视为已清除，从加载起消失。未知类型不能自动套用现有规则。

一次有效方向输入依次处理移动、原压板能量及其再现伤害、同快照攻击目标锁定、统一攻击死亡，最后更新清怪能量。不因新开门追加第二轮攻击。无效移动和免费 C 不推进攻击。表现层重建攻击时使用开门之前的锁定屏障状态，避免死去的火龙因门最终消失而多喷一次火；失活地面标记和现有开关效果继续复用。

用户另已明确确认：哥布林对相邻的哥布林也发动上下左右一格攻击，同一步互杀。相邻英雄仍会同时死亡，不能因攻击者本步被杀而取消其攻击；不包括斜角，不扩展未知未来怪物或尚未确认的隔栅栏攻击。红人仍可隔水晶推动整列，绿色仍不能拉哥布林。死亡对象不再占格、攻击或成为交换目标。

撤销一次完整恢复位置、生命、水晶身份、两类能量、压力和实际行动统计，并保持当前英雄选择。重开还原初始怪物与能量；任何英雄死亡时仍只可撤销。

第31关已按用户最后确认补全为11×8：新增顶排78–88仅85是墙，原1–77统一向下平移一格。编号映射保存在 `levels/mappings/north_31_markers.json`。旧不完整地图的搜索诊断不是最终地图的无解结论；未添加推出棋盘死亡或其它机制。确认后的完整地图使用96次实际行动、29次推动通关：第72/73步使用新增79/78转向，第77步两只哥布林相邻互杀并令清怪能量消失，第96步英雄抵达目标；不宣称最短路线。

验证入口：`tools/check_north_31.py` 独立重放全部身份与动作；`tests/north_31_regression.gd` 检查最终地图、完整路线、整步撤销、死亡锁及边界；`tests/north_31_scene.gd` 用真实键盘和屏幕输入验证通关、撤销复活、菜单与窗口适配。公共机制夹具是 `tests/monster_clear_energy_regression.gd` 和 `tests/monster_clear_energy_scene.gd`，覆盖所有已实现怪物类型、初始零怪、最后死亡、旧压板类型共存、视线/碰撞及开门不追加攻击轮。它们均已接入 `tools/verify.py`；最终执行范围和结果另见 `docs/verification/north_31_scope.json`。
